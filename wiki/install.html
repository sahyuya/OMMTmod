Guide 01

導入と最初の起動

Minecraft版に合ったOMMTと前提MODを入れ、最初のMIDIがライブラリへ表示されるところまで進めます。

  • 必要なもの
  • 対応ファイル

必要なもの

OMMTはクライアント専用のFabric MODです。OMMT本体に加えて、同じMinecraft版向けの次のMODをクライアントへ導入します。

  • Fabric Loader
  • Fabric API
  • Fabric Language Kotlin
  • Fabric GUI ImGui
サーバーのmodsフォルダーには入れませんOMMTは自分のMinecraftクライアントで動く編集画面です。Modrinth Appなどで使用中のプロフィールのmodsフォルダーへ入れてください。

Minecraft版に合うファイルを選ぶ

OMMTはMinecraft版ごとに別のJARです。ファイル名の末尾と、起動するMinecraftのバージョンを一致させてください。

MinecraftOMMT 2.1.0Java
1.21.11OyasaiMusicMidiTranslator-2.1.0-fabric1.21.11.jar21
26.1.2OyasaiMusicMidiTranslator-2.1.0-fabric26.1.2.jar25
26.2OyasaiMusicMidiTranslator-2.1.0-fabric26.2.jar25
前提MODの正確な版各OMMT JARには、そのMinecraft版で必要なFabric Loader、Fabric Language Kotlin、Fabric GUI ImGuiの条件が記録されています。ランチャーに互換性エラーが出た場合は、エラーに表示された版を確認してください。

導入手順

  1. Fabricプロフィールを用意する。
    遊ぶMinecraft版と一致するFabric Loaderのプロフィールを作成します。
  2. 前提MODを入れる。
    Fabric API、Fabric Language Kotlin、Fabric GUI ImGuiをプロフィールのmodsへ入れます。
  3. OMMT本体を入れる。
    Minecraft版と一致するOMMT JARを同じmodsへ入れます。
  4. Minecraftを一度起動する。
    タイトル画面まで起動すると、OMMT用のフォルダーと設定ファイルが用意されます。

MIDIを置くフォルダー

OMMTはゲームディレクトリの中に次の2つを使用します。

場所入るもの用途
OMMT/midi.mid／.midi元になるMIDIを読み込む
OMMT/saves.ommt編集途中の状態を保存・再開する

パスを手で入力する必要はありません。エディター左側のMIDIライブラリにある「フォルダーを開く」を押すと、MIDIを置く場所を直接開けます。ファイルを追加した後は「更新」を押してください。

例: 「spring-concert.mid」を追加する

「フォルダーを開く」→開いた場所へspring-concert.midをコピー→OMMTへ戻って「更新」の順に操作します。左のMIDI一覧にファイル名が表示されたら準備完了です。

OMMTを最初に開く

  1. ワールドまたはサーバーへ入ります。
  2. Oを押してOMMTを開きます。これは初期設定で、Minecraftのキー設定から変更できます。
  3. 左のMIDIライブラリで曲を選択します。
  4. 「MIDI読込」を押すか、曲をダブルクリックします。

Minecraftの言語が日本語ならOMMTも日本語で表示されます。それ以外の言語では英語表示です。

読み込みだけでは送信されませんMIDIの選択、編集、ローカル試聴、.ommt保存はクライアント内の作業です。実際に送信するのは、後で「下書き送信」を押したときだけです。
