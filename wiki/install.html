Guide 01 · Install

導入と最初の起動

Minecraft版に合ったOMMTと前提MODを入れ、最初の曲がライブラリに表示されるところまで進めます。

このページ
  • 必要なもの
  • 対応バージョン
  • 導入手順
  • 曲ファイルのフォルダー
  • 最初に開く

必要なもの

OMMTはクライアント専用のFabric MODです。本体のほかに、同じMinecraft版向けの次のMODを自分のクライアントへ導入します。

  • Fabric Loader
  • Fabric API
  • Fabric Language Kotlin
  • Fabric GUI ImGui
サーバーのmodsフォルダーには入れません

OMMTは自分のMinecraftで動く編集画面です。Modrinth Appなどで使っているプロフィールのmodsフォルダーへ入れてください。

対応バージョン

維持対象はMinecraft 26.2のみです。ファイル名の版がMinecraft版と一致するOMMTを選んでください。

項目版
Minecraft26.2
OMMTOyasaiMusicMidiTranslator-3.0.0-fabric26.2.jar
Java25
Fabric Loader0.19.3
Fabric API0.158.0+26.2
前提MODの正確な版

OMMTのJARには必要な前提MODの条件が記録されています。ランチャーに互換性エラーが出た場合は、エラー文に表示された版を確認してください。

導入手順

  1. Fabricプロフィールを用意する。
    遊ぶMinecraft版（26.2）と一致するFabric Loaderのプロフィールを作成します。
  2. 前提MODを入れる。
    Fabric API、Fabric Language Kotlin、Fabric GUI ImGuiをプロフィールのmodsへ入れます。
  3. OMMT本体を入れる。
    Minecraft版と一致するOMMTのJARを同じmodsへ入れます。
  4. Minecraftを一度起動する。
    タイトル画面まで起動すると、OMMT用のフォルダーと設定ファイルが用意されます。

曲と編集データを置くフォルダー

クライアント起動時に、ゲームディレクトリの中のOMMTへ次の3つが作られます。エディターを開く必要はありません。

場所入るもの用途
OMMT/midi.mid／.midi元のMIDIを読み込む
OMMT/nbs.nbsNote Block Studio形式（v0～v6）の曲を読み込む
OMMT/saves.ommt編集途中を保存・再開する

パスを手で入力する必要はありません。ライブラリのMIDI・NBS・保存タブにある「フォルダーを開く／OPEN FOLDER」で直接開けます。ファイルを追加した後は「更新／REFRESH」を押してください。サブフォルダー内のファイルは一覧に出ません。

例: 「spring-concert.mid」を追加する

MIDIタブで「フォルダーを開く」→開いた場所へspring-concert.midをコピー→OMMTへ戻って「更新」の順に操作します。NBSならNBSタブからOMMT/nbsへ置きます。

OMMTを最初に開く

  1. ワールドまたはサーバーへ入る。
  2. Oを押してOMMTを開く。
    初期設定のキーです。Minecraftのキー設定から変更できます。
  3. 左ライブラリで曲を選ぶ。
    MIDI・NBS・保存タブを切り替えて目的のファイルを選びます。
  4. 読み込む。
    上部の「MIDI読込／LOAD MIDI」「NBS読込／LOAD NBS」「保存読込／LOAD SAVE」を押すか、ファイルをダブルクリックします。

Minecraftの言語が日本語なら日本語、それ以外なら英語で表示されます。

読み込みだけでは送信されません

選択・編集・ローカル試聴・.ommt保存はクライアント内の作業です。サーバーへ送られるのは「下書き送信」を押したときだけです。
