Layout

Toggle the library, Note Inspector, bottom editor panels, and ghosting of other parts. Drag panel titles to move, dock, or tab them; drag borders to resize.

ItemDefault
MIDI libraryShown
Note InspectorShown
Bottom editor panels (volume, pan, tempo, release)Shown
Ghost other partsON

Press SAVE CURRENT LAYOUT to persist an arrangement explicitly, or RESTORE DEFAULT LAYOUT to redo it.

Example: a wide piano roll

Stack volume, pan, tempo, and release as four tabs at the bottom, keep the inspector right and the library left, and the central roll stays wide.

Keymap

Press a row's button, then type the new combination. Backspace (or Delete) unbinds, Esc cancels. Defaults are listed in the editing shortcut table.

Mouse wheel

ModifierDefault
NonePitch scroll
ShiftTimeline scroll
CtrlTime zoom
AltPitch zoom

Each modifier accepts timeline scroll, time zoom, pitch zoom, pitch scroll, or none. Range-select (default Shift), add-to-selection (default Ctrl), and the pan button (right/middle click) can change too. Confirm/Apply (default Enter) only works while editing a field.

Watch for duplicates

Binding the same combination to several actions makes them hard to trigger. Test note selection and playback after changes.

Share

Pack colors, window layout, keymap, and display settings into one OMMTCFG1: string. This page is for backup and sharing only — edit colors under Style and layout under Layout first.

Export

  1. Press EXPORT.
  2. Press COPY on the shown string.
  3. Keep it somewhere only you can find.

Import

  1. Copy a settings string.
  2. Press PASTE in OMMT's settings.
  3. Press IMPORT and check layout and controls.
No songs included

Settings strings contain no MIDI, NBS, .ommt, notes, or titles. Copy files under OMMT/midi, OMMT/nbs, and OMMT/saves separately to move songs.
