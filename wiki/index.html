Oyasai Server MIDI / NBS workspace

MIDIやNBSを、Minecraftの中で整える。

OMMT（OyasaiMusicMidiTranslator）は、おやさいサーバーで使うMIDI／Note Block Studio（NBS）の曲を読み込み、ピアノロールで編集し、OyasaiMusicの非公開下書きへ送るためのクライアント専用MODです。このWikiでは、導入から送信までを手順ごとに説明します。

導入から始める 編集操作を見る
OMMT · MIDIワークスペース
おやさいサーバー専用です

MIDI／NBSの編集とローカル試聴はどのワールドでも行えますが、「下書き送信」はおやさいサーバーでのみ使用します。

Basic flow

曲を送るまでの5段階

  1. 元ファイルを置くMIDIはOMMT/midi、NBSはOMMT/nbsへ入れます。
  2. 読み込むライブラリから選び、ピアノロールへ展開します。
  3. 編集するノート、パート、楽器、音量、テンポを整えます。
  4. 試聴・保存音を確認し、.ommtで続きから再開できるようにします。
  5. 下書き送信おやさいサーバーへ非公開下書きとして送ります。

始める前に知っておくこと

  • Minecraftの言語が日本語なら日本語、それ以外なら英語で表示されます。
  • 元のMIDI／NBSと、編集途中を保存する.ommtは別のファイルです。
  • 「編集を保存」だけではサーバーへ送信されません。
  • 「下書き送信」に成功しても自動公開はされず、非公開下書きとして作成されます。
  • 他者が作ったMIDI／NBSは、利用・共有してよいものだけを使用してください。
