Oyasai Server MIDI / NBS workspace

MIDIやNBSを、Minecraftの中で整える。

OMMTは、おやさいサーバーで使うMIDI／Note Block Studio（NBS）の曲を読み込み、ピアノロールで編集し、OyasaiMusicの非公開下書きへ送るためのクライアントMODです。このWikiでは、初めての読み込みから送信までを操作例つきで説明します。

導入から始める 編集操作を見る
OMMT · MIDIワークスペース
おやさいサーバー専用です OMMTは一般サーバー向けのアップロードMODではありません。MIDI／NBSの編集とローカル試聴は単体でも行えますが、「下書き送信」はおやさいサーバーでのみ使用します。

Basic flow

曲を送るまでの5段階

  1. 元ファイルを置くMIDIはOMMT/midi、NBSはOMMT/nbsへ入れます。
  2. 読み込むMIDI／NBSライブラリから選び、ピアノロールへ展開します。
  3. 編集するノート、パート、音量、テンポなどを整えます。
  4. 試聴・保存音を確認し、必要なら.ommtで続きから再開します。
  5. 下書き送信おやさいサーバーへ非公開下書きとして送ります。

Choose a guide

目的から読む

GUIDE 01

OMMTを導入する

対応JARと前提MODを確認し、最初のMIDIまたはNBSをライブラリへ追加します。

 GUIDE 02

曲を読み込む

MIDI／NBSの違いと全体・パート表示を確認し、編集を始めます。

 GUIDE 03

ノートを整える

選択、範囲選択、移動、長さ変更、音高や楽器の調整を行います。

 GUIDE 04

パートを整理する

選択音からパートを作り、既存パートへ移動し、名前を付けます。

 GUIDE 05

編集途中を保存する

.ommtプロジェクトとして保存し、後日そのまま続きを編集します。

 GUIDE 06

おやさいサーバーへ送る

試聴と確認を終えた曲をOyasaiMusicの非公開下書きへ送信します。

始める前に知っておくこと

  • 編集画面はMinecraftの言語が日本語なら日本語、それ以外なら英語で表示されます。
  • 元のMIDI／NBSと、編集途中を保存する.ommtは別のファイルです。
  • 「編集を保存」だけではサーバーへ送信されません。
  • 「下書き送信」に成功しても自動公開はされず、非公開下書きとして作成されます。
  • 他者が作ったMIDI／NBSは、利用・共有してよいものだけを使用してください。
