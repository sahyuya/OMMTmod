Oyasai Server MIDI / NBS workspace

Arrange MIDI and NBS inside Minecraft.

OMMT (OyasaiMusicMidiTranslator) is a client-only mod for loading MIDI and Note Block Studio (NBS) songs, editing them on a piano roll, and submitting them as private drafts to OyasaiMusic on the Oyasai server. This wiki walks you from installation to submission.

OMMT · MIDI workspace
Built for the Oyasai server

Editing and local preview work in any world, but draft submission only works on the Oyasai server.

Basic flow

Five steps to submit a song

  1. Place source filesPut MIDI files in OMMT/midi and NBS files in OMMT/nbs.
  2. LoadPick a song from the library to open it on the piano roll.
  3. EditArrange notes, parts, instruments, volume, and tempo.
  4. Preview & saveListen locally and save an .ommt project to resume later.
  5. Submit draftSend it as a private draft to the Oyasai server.

Before you start

  • OMMT follows your Minecraft language: Japanese for Japanese, English otherwise.
  • Source MIDI/NBS files and .ommt projects are separate files.
  • Saving a project does not submit anything to a server.
  • Submitting creates a private draft — nothing is published automatically.
  • Only use MIDI/NBS files you are allowed to use and share.
