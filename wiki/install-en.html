Install & First Launch

Install OMMT with the matching Minecraft version and required mods, up to seeing your first song in the library.

On this page
  • Requirements
  • Supported versions
  • Installation steps
  • Song folders
  • Opening OMMT

Requirements

OMMT is a client-only Fabric mod. Alongside OMMT itself, install these mods for the same Minecraft version on your client.

  • Fabric Loader
  • Fabric API
  • Fabric Language Kotlin
  • Fabric GUI ImGui
Do not put OMMT in a server mods folder

OMMT is an editor that runs on your own Minecraft client. Place it in the mods folder of the profile you play with, e.g. via the Modrinth App.

Supported versions

Only Minecraft 26.2 is supported. Pick the OMMT file whose version matches your Minecraft version.

Exact dependency versions

The OMMT JAR records the required versions of its dependencies. If your launcher reports a compatibility error, check the versions named in the error message.

Installation steps

  1. Prepare a Fabric profile.
    Create a Fabric Loader profile matching the Minecraft version (26.2) you play.
  2. Add the required mods.
    Put Fabric API, Fabric Language Kotlin, and Fabric GUI ImGui into the profile's mods folder.
  3. Add OMMT.
    Put the matching OMMT JAR into the same mods folder.
  4. Launch Minecraft once.
    Starting up to the title screen prepares OMMT's folders and config files.

Song and project folders

When the client starts, three folders are created inside OMMT in the game directory. You do not need to open the editor first.

LocationContentsUsed for
OMMT/midi.mid / .midiLoading source MIDI files
OMMT/nbs.nbsLoading Note Block Studio songs (v0–v6)
OMMT/saves.ommtSaving and resuming in-progress edits

No need to type paths by hand: each library tab (MIDI, NBS, saves) has an OPEN FOLDER button. After adding files, press REFRESH. Files inside subfolders are not listed.

Example: adding “spring-concert.mid”

On the MIDI tab, choose “Open folder”, copy spring-concert.mid there, return to OMMT, and press “Refresh”. For NBS, open OMMT/nbs from the NBS tab and place the file there.

Opening OMMT

  1. Join a world or server.
  2. Press O.
    This is the default key. You can change it in Minecraft's key settings.
  3. Pick a song in the left library.
    Switch between the MIDI, NBS, and saves tabs.
  4. Load it.
    Press “LOAD MIDI”, “LOAD NBS”, or “LOAD SAVE” at the top, or double-click the file.

OMMT displays Japanese when Minecraft's language is Japanese, and English otherwise.

Loading alone submits nothing

Selecting, editing, local preview, and .ommt saving all happen on your client. The server receives something only when you press draft submission.
