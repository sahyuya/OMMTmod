Install and open OMMT

Match your Minecraft and mod versions, then open the editor.

On this page
  • Requirements
  • Open the editor
  • Where files go

Requirements

The maintained target is Minecraft Java Edition 26.2 with Fabric. OMMT cannot be installed on Bedrock Edition.

  • OMMT JAR for 26.2
  • Fabric Loader
  • Fabric API
  • Fabric Language Kotlin
  • Fabric GUI ImGui

Use the dependency versions listed with your OMMT release. Do not mix older 1.21.11 or 26.1.2 builds into this profile. Check dependencies even when installing with a launcher.

Open the editor

  1. Install the mods in your launcher’s 26.2 profile and start Minecraft.
  2. Enter a world and press O.
  3. The OMMT library and piano roll should appear.

If nothing opens, find OMMT in Minecraft’s key bindings. Change the editor key if another mod uses it.

Where files go

OMMT creates these folders inside the game directory of the profile you launch. A different launcher profile has a different directory.

File typeFolder
MIDI (.mid / .midi)OMMT/midi
Note Block Studio (.nbs)OMMT/nbs
Saved project (.ommt)OMMT/saves

Select MIDI, NBS, or SAVE in the library. Use “OPEN FOLDER”, add your file, and press “REFRESH”.
