Read and move around the piano roll

Horizontal position is time; vertical position is pitch. A note’s width shows its duration, and its color identifies its part. Numbers above the roll mark bars.

ActionDefault input
Move verticallyWheel
Move along the timelineShift + wheel
Zoom timeCtrl + wheel
Zoom pitchAlt + wheel
Pan the viewRight drag
Fit the songF

Select, move, and resize

  • Click: select a note without moving it.
  • Ctrl + click a note: add to or toggle the selection.
  • Shift + drag: select a rectangular region.
  • Drag selected notes: change their time and pitch.
  • Drag a note edge: change its duration.
  • Ctrl + click empty space: add a note.

Ctrl + A selects notes in the current view. Delete removes the selection; Ctrl + Z undoes an edit.

Align notes with snap

Snap aligns moves and resizes to a rhythmic grid. The SNAP button or S cycles through 1/4 → 1/8 → 1/16 → 1/32 → 1/64 → OFF.

Try 1/16 first, and use 1/32 or 1/64 for finer ornaments. Turn snap off only where you want free timing. Zooming the view does not change the snap setting.

Edit precise values

Start time uses milliseconds. Duration can use milliseconds or note lengths from 1/1 to 1/64. Pitch buttons -12 / -1 / +1 / +12 move by an octave or a semitone.

Confirm typed values with APPLY. Pitch, volume, and pan changes across a selection are relative to the representative note, preserving differences until a value reaches its allowed limit.

Example: raise the melody by an octave

  1. Open the melody part.
  2. Select the phrase to change.
  3. Use +12 and listen to the result.

To reorganize groups of notes, see parts.
