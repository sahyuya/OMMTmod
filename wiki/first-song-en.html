Send your first song

Start with a short song and follow the complete import-to-upload workflow.

On this page
  • 1. Import a song
  • 2. Listen and adjust the view
  • 3. Make one small edit
  • 4. Save your edit
  • 5. Upload to the Oyasai Server

1. Import a song

  1. Put MIDI files in OMMT/midi or NBS files in OMMT/nbs.
  2. Choose the matching library tab and press “REFRESH”.
  3. Double-click the file, or select it and press “LOAD MIDI” / “LOAD NBS”.

Each horizontal bar in the piano roll is one note. Time runs left to right; higher notes appear higher on the screen.

2. Listen and adjust the view

Press Space to play or pause, and Home to return to the start. “FIT” (F) fits the song’s time and pitch range into view.

Turn FOLLOW off if you want the view to stay still during playback. Listen for the melody before changing every instrument; a Minecraft arrangement will not necessarily sound like the original synthesizer.

3. Make one small edit

  1. Click a note to select it.
  2. Lower its volume a little in NOTE INSPECTOR.
  3. Press “APPLY” and listen to the surrounding phrase.
  4. Use Ctrl + Z to undo if needed.

Start with one note so the scope of the change is clear. See note editing when you are ready to edit a selection.

4. Save your edit

Give the song a useful name and press “SAVE PROJECT”. A .ommt file is saved in OMMT/saves. Open it from the SAVE library tab to resume.

Your original MIDI or NBS file is not overwritten.

Save a project to keep your changes. Saving locally and uploading are separate actions.

5. Upload to the Oyasai Server

  1. Connect to the Oyasai Server.
  2. Open your saved edit in OMMT and check the title and contents.
  3. Press “UPLOAD DRAFT” and wait for completion.

This creates a private draft, not a public release or a broadcast to everyone. Manage the uploaded song through OyasaiMusic on the server.

If upload fails, read the error before trying again. See upload troubleshooting.
