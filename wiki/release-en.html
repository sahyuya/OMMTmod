Add pseudo-release to long notes

Retrigger a note while changing its volume to create a fade or swell.

Retriggering, not stretching

Pseudo-release repeats a sound at intervals during a long note. It does not stretch the original sample, so repeated attacks may be audible depending on the instrument and interval.

It applies to selected notes only. Test one long note before applying it to a phrase.

Controls

ControlMeaning
ThresholdNote length that qualifies for retriggering; milliseconds or 1/1–1/64
IntervalTime between retriggers; milliseconds or 1/1–1/128
Start / end volumePercentage of the original note volume, from 0 to 100%
Curve / middle pointsVolume envelope; up to two middle points, movable horizontally and vertically

Use note lengths for beat-based timing, or milliseconds for a fixed time interval.

Try it on one note

  1. Select a long note and open RELEASE.
  2. Enable it and set the threshold below that note’s duration.
  3. Try a 1/16 interval, 100% start, 30% end, and SMOOTH curve.
  4. Press APPLY and listen. Adjust the interval or instrument if repeated attacks are too prominent.

These values are a starting example. Short notes and some percussion may not benefit. Select the affected notes and use CLEAR SELECTED to remove the effect.
