Choose instruments and sounds

Select the notes to change, choose a sound, and listen to it in context.

On this page

  • Other Minecraft sounds

Note block instruments

  1. Select the notes. To change a whole part, show that part and select all.
  2. Choose an instrument in NOTE INSPECTOR.
  3. Press APPLY and listen.

The list includes the corresponding block family. The 26.2 target supports four trumpet variants; imported NBS trumpets also need a compatible server plugin.

MIDI instruments are mapped to Minecraft instruments, not to the original synthesizer samples. Choose a different instrument if it makes the melody clearer.

Other Minecraft sounds

Select Other Minecraft sound to reveal the search field, event list, and fixed-pattern selector.

  1. Search for part of a sound ID, such as bell.
  2. Choose an event from the results.
  3. Select a fixed pattern when the event has several variants.
  4. Apply and preview.

A fixed pattern chooses a specific variation of the same event; it is separate from pitch. Not every NBS custom sample can be represented by a Minecraft sound. Read any conversion notices shown on import.

Pitch range and the optional resource pack

The piano roll keeps the source pitch visible and shades notes outside the vanilla range. Different shading does not mean a note is broken.

Without the extension pack, playback fits notes into the vanilla range. With a compatible loaded pack, supported sounds can use an extended range. The pack is not required to use OMMT.

On the Oyasai Server, use /mm rp allow or /mm rp deny to opt in or out. Check pack state when local preview and server playback sound different.
