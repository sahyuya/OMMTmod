Troubleshooting

Find the closest symptom below. If it persists, report the steps and relevant details.

On this page

  • Draft upload fails
  • What to include in a report

Editor will not open or a file is missing

  • Editor will not open: check Minecraft 26.2, required mods, and conflicting Minecraft key bindings.
  • File not listed: check the library tab, active launcher profile directory, and extension, then refresh.
  • OPEN FOLDER fails: open the profile directory through your launcher and navigate to OMMT/midi, nbs, or saves.
  • Import fails: record the error and try a small file to see whether the problem affects every import. Keep the original file.

No sound, or unexpected sound or pitch

  1. Check Minecraft’s volume and whether the note volume is zero.
  2. Select one short note and try previewing it.
  3. Check the instrument, fixed sound pattern, and extension-pack state.
  4. Look for fallback-sound notices from the NBS import.

Record whether the issue happens in local preview, server playback, or both.

Selection, edits, or layout behave unexpectedly

  • Only one note changes: select the intended notes first. Open a part and select all to edit the whole part.
  • Dragging changes the timing: check snap; disable it temporarily for free timing.
  • Edits seem lost: open the .ommt project from SAVE, not the original MIDI or NBS.
  • A panel is missing: check visibility and layout settings. Export settings before resetting a layout you want to keep.
  • The editor is slow: focus on one part and zoom into the passage. Report the file and symptoms if it only affects a particular song.

Draft upload fails

Connect to the Oyasai Server and check that you have upload permission. A disconnect before completion or an error does not mean the upload succeeded.

Save a local .ommt project and record the error. If the problem started after changing a sound, include that change and your OMMT version in the report. Successful import does not guarantee the server can accept the result.

What to include in a report

  • Minecraft and OMMT versions
  • Your steps, expected result, and actual result
  • A screenshot of the error and the time it happened
  • The source file or .ommt project, if you can share it
  • For audio issues: local preview or server playback, and whether the pack was loaded

Report in the OMMT discussion thread inside showcase on the Discord server. Remove unnecessary personal or connection details before sharing logs.
