When Stuck

Check common issues by cause. If nothing helps, contact the report destination at the end.

On this page
  • Missing files
  • Display & controls
  • Submission & playback
  • Restoring layout

Missing or unloadable files

MIDI files do not appear

  • Check the extension is .mid or .midi.
  • Check you placed them where “Open folder” points.
  • Press “Refresh” after adding files.

NBS files do not appear

  • Check the extension is .nbs.
  • Open OMMT/nbs from the library's NBS tab.
  • Press “Refresh” after adding files.

Cannot open folders

OMMT uses Explorer on Windows, open on macOS, and xdg-open on Linux. On failure, open the active profile's game directory yourself and move to OMMT/midi or OMMT/nbs. These are created at client startup.

Cannot find .ommt files

Switch the library to the SAVE tab instead of MIDI/NBS. Save files live in OMMT/saves.

Display & controls feel wrong

Buttons or rows are cut off

Lower the OMMT UI scale a little and drag window borders wider. Tabbing unused panels together widens the piano roll.

Wheel direction or role feels wrong

Change per-modifier actions under Settings → Keymap. Matching your usual DAW reduces confusion.

A key does not do what you expect

Check the keymap for the same combination bound to several actions.

Submission & playback issues

Draft submission is unavailable or fails

  • Check you are connected to the Oyasai server.
  • Check you have submission permission.
  • Do not start submissions back-to-back; wait for completion or an error.
  • When an error names unusable sounds or song size, fix those parts and resend.

Checking for buffered playback

Search OMMT/BufferedPlayback in the profile's logs/latest.log. It never appears in game chat.

“Bundled resource pack is outdated” message

Follow the chat guidance to update (the mentioned command works too). Until then, playback uses the normal range.

Restoring a broken layout

If you exported a settings string while things were fine, import it. Without a backup, quit Minecraft, move the profile's config/ommt-imgui-layout.ini elsewhere, and restart to rebuild the default layout. Keep the moved file until you confirm recovery.

Where to report

Report to the OMMT thread in the showcase channel on the Oyasai server Discord.

Open the Oyasai server Discord

These details make the situation easier to confirm.

  • Minecraft version
  • OMMT version
  • What you did and what you expected
  • What actually happened
  • Screenshots or logs when possible

Attach MIDI/NBS files only when you hold sharing rights and are fine sharing them.
