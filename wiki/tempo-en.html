Change tempo during a song

Place tempo points, set their BPM, and choose how the tempo changes between them.

On this page
  • Add a tempo point
  • Choose a curve
  • Example: slow down the ending

Add a tempo point

BPM describes the song’s speed. Use the TEMPO panel for changes within the song.

  1. Move the playhead to the intended position.
  2. Press ADD AT PLAYHEAD.
  3. Set BPM and the curve, then press APPLY.
  4. Play from before the change to check it.

Inspect imported tempo points before adding new ones. A MIDI file may already contain the change you want.

Choose a curve

CurvePurpose
STEPSwitch tempo at a boundary
LINEARChange tempo along a straight slope
SMOOTHMake a smooth transition

Check the plotted line to confirm which interval you have changed, and always listen to that passage afterward.

Example: slow down the ending

  1. Place a point where the slowdown starts and another where it ends.
  2. Set the first to 120 BPM and the second to 100 BPM.
  3. Use a LINEAR or SMOOTH connection for the interval.
  4. Listen from a few bars earlier and adjust the speed and transition length.

If the change feels instantaneous, check for a STEP curve or points placed too close together.
